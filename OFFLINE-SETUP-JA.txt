Moira POS iPadオフライン版

【変更内容】
・画面の読み込み、保存、初期化で /api/state を使用しません。
・伝票、会計履歴、スタッフ、顧客、給与、予約、売掛などをiPad内の保存領域へ自動保存します。
・Moira/DAYS、本番/テストを別々のキーで保存します。
・旧版のローカル保存データがある場合は初回起動時に移行します。
・Service Workerで画面とNext.jsのJavaScriptをキャッシュします。
・npm run build が正常終了することを確認済みです。

【PCで確認する手順】
1. npm install
2. npm run build
3. npm run start
4. iPadとPCを同じWi-Fiへ接続して http://PCのIPアドレス:3000 を開く

【iPadだけで使うための条件】
・このプロジェクトをVercel等のHTTPS URLへ公開してください。
・iPadで公開URLをオンライン状態で一度完全に開きます。
・画面操作と保存を確認後、Safariの共有メニューからホーム画面へ追加します。
・その後にWi-Fiを切り、ホーム画面アイコンから起動テストします。

【重要】
・データはiPad内に保存されるため、SafariのWebサイトデータ削除やアプリ削除で消える可能性があります。
・営業終了時にJSONバックアップを保存してください。
・別のiPadへデータは自動同期されません。JSONバックアップ/復元を使用してください。
